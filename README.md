# MicroPython Examples with ESP32 DevKit
Repository of MicroPython examples with the ESP32 DevKit. This repo contain begginer friendly examples. If it is your first time using MicroPython, ESP32 DevKit, or just new to embedded, I would recommend the use of [Thonny IDE](https://thonny.org/). Otherwise, VSCode & esptool may be used. For simulation, I would recommend [Wokwi](https://wokwi.com/esp32). All correspondent credits for the libraries and scripts authors when used.
